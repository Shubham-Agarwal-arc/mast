# MAST

MAST is a VS Code AI tutor for machine-learning practitioners that helps users learn from their debugging errors rather than simply giving them fixes. The production design combines local error classification, DKT-based mastery tracking, mastery-gated retrieval, and a constitutionally enforced Socratic dialogue.
